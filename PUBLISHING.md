# Publishing this portfolio to GitHub Pages

1. Upload the complete repository contents to the `main` branch, preserving the directory structure.
2. Open **Settings → Pages** and select **GitHub Actions** as the build and deployment source if it is not already selected.
3. Open the **Actions** tab and wait for the portfolio deployment workflow to succeed.
4. Use the live URL shown by the deployment workflow and test the site, report, battlecard and AI-workflow PDF in a signed-out browser.
5. Only after verifying the live public URLs, replace the old portfolio URL in the CV. Suggested CV wording is in [docs/cv-integration-copy.md](docs/cv-integration-copy.md).

## Portfolio integrity

The AI workflow is a retrospective portfolio demonstration using IBM- and Jio-informed workstreams. It does not claim that AI was used in the original roles or attribute historical campaign outcomes to AI. Proposed Recruiterflow copy and experiments are hypotheses, not shipped work or measured results.

Pricing and product details in the competitor research are a dated public-source snapshot and should be rechecked before external use.
