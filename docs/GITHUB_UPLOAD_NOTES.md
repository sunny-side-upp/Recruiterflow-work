# Repository and portfolio contents

This repository consolidates the Recruiterflow APMM portfolio into one public project.

## Included

- Responsive portfolio website: `index.html`, `styles.css`, `script.js`
- Competitive-intelligence report: `report.pdf`
- Sales-enablement battlecard: `battlecard.pdf`
- AI-assisted marketing workflow report: `ai-assisted-marketing-workflow.pdf`
- Editable Markdown samples under `docs/`
- Illustrations and framework visuals under `assets/`
- GitHub Pages workflow under `.github/workflows/pages.yml`

## Integrity notes

- Public product/pricing information is a dated snapshot and can change.
- Proposed messaging and experiments are hypotheses, not claims that changes were shipped or tested.
- AI workflow content is a portfolio demonstration, not a claim that AI was used during the original IBM/Jio employment.
- Do not share confidential customer, employee or partner information in unapproved AI tools.
- Concept graphics are illustrative, not screenshots of Recruiterflow software.

## Publishing

In GitHub, choose **Settings → Pages → GitHub Actions** for the source. Check the Actions tab after pushing to `main` and verify the generated site and PDFs while signed out.
